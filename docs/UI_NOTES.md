# UI 구현 사항 요약

## 개발 환경 및 구조
- React 19, TypeScript, Vite 8 기반으로 `src/ui/` 내에 모든 UI 컴포넌트를 작성했습니다.
- 전역 상태 관리 및 탭 간 데이터 공유를 위해 `AppContext`를 구성하여 `App.tsx`에서 최상위 뷰를 관리합니다.
- `App.css`에 CSS Custom Properties(Variables)를 사용해 테마와 Safe-area insets를 반영했습니다.
- `lucide-react`를 설치하여 아이콘을 적용했습니다.

## 주요 화면 구현
1. **소설 (Novel)**
   - 리스트 및 에디터 뷰로 구성.
   - `한국어 / 원문 / 함께 보기` 모드 전환을 제공하며, 세그먼트 클릭 시 Action Sheet를 띄워 수정, 다시 번역, 삭제, 장면 그리기 등의 상호작용이 가능합니다.
   - "누락된 한국어 번역하기", "용어 자동 추출" 기능을 상단 설정 시트에서 지원합니다.
2. **채팅 (Chat)**
   - 채팅방 목록과 개별 채팅룸을 제공하며 캐릭터, 닉네임, 프롬프트, 첫 메시지 등을 설정해 새로운 채팅을 생성할 수 있습니다.
   - 각 말풍선에 대해 "원문 보기" 토글을 제공하며, 클릭 시 소설과 동일한 수정/삭제/장면 그리기 기능을 지원합니다.
3. **이미지 (Image)**
   - 한국어 묘사를 태그로 변환 시 스트리밍을 지원하며, 세부 생성 옵션(모델, 크기, 스텝, 샘플러, 시드 등)을 하단 시트로 분리하여 직관적인 조작이 가능하도록 했습니다.
   - 생성된 이미지를 브라우저의 IndexedDB에서 불러와 갤러리 형태로 제공하며, 선택 시 전체 화면으로 볼 수 있습니다. (시드 및 프롬프트 재사용, 다운로드, 공유 지원)
   - 소설 및 채팅 탭에서 "이 장면 그리기" 선택 시, AppContext의 `imageDraftText`를 통해 해당 텍스트를 이미지 탭으로 넘겨 바로 태그 변환을 시작하도록 연동했습니다.
4. **설정 (Settings)**
   - API 키 확인을 통해 사용자 상태(Anlas, 만료일)를 표시하며, 출력 방식과 번역 스타일 등 다양한 생성을 위한 변수를 설정할 수 있습니다.
   - 데모 모드 지원, 기기 백업(가져오기/내보내기) 기능을 연동했습니다.

## PWA 및 최적화
- `manifest.webmanifest`, 서비스 워커(`sw.js`), 192/512 크기의 SVG 아이콘을 `public` 폴더에 배치하여 PWA 설치를 지원합니다.
- `vitest` 및 `tsc` 빌드가 원활하게 성공하도록 `src/core/`의 모든 타입 제약과 API를 안전하게 사용했습니다.

모든 코드는 `src/core/` 내부를 수정하지 않고 개발되었으며, `npm run build`와 `npm test`가 통과되도록 타입 에러 없이 작성되었습니다.

## Claude 검토 후 수정 사항

Gemini 작업은 파일 편집만 허용된 모드로 실행돼서 빌드를 돌려보지 못했어요. 검토하면서 아래를 고쳤어요.

- 빌드 오류 11건 (사용하지 않는 import, `KNOWN_TEXT_MODELS` import 누락)
- 입력 중 글자 누락: 제목·시스템 프롬프트·용어집 입력이 IndexedDB 저장을 기다린 뒤에 state를 바꿔서, 빠르게 치면 글자가 사라졌음 → state를 먼저 바꾸고 저장은 뒤에서
- 생성 중에 설정을 고치면 생성 결과가 그 수정을 덮어씀 → 결과에서는 본문(segments/messages)만 반영
- 탭을 옮기면 화면이 언마운트되어 열어둔 소설·채팅과 진행 중인 생성이 사라짐 → 네 탭을 항상 마운트
- "직접 쓰기"와 문단·메시지 수정이 busy 잠금, 진행 표시, 오류 처리 없이 실행됨 → 공통 run()으로 통일
- 용어 자동 추출이 본문이 아니라 시스템 프롬프트에서 추출함 → 본문 영어에서 추출, 체크리스트로 골라 추가
- 이미지 크기 선택 시 width/height를 두 번 나눠 갱신해서 width가 되돌아감 → 한 번에 갱신
- 갤러리 썸네일이 렌더마다 object URL을 새로 만듦 → 컴포넌트 수명에 묶음
- 사용자 묘사도 "소설 장면" 모드로 태그 변환함 → 직접 쓴 묘사와 "이 장면 그리기"를 구분
- 태그 변환이 전역 busy 잠금을 무시함(동시 요청 위험) → 잠금 + 중지 버튼
- 모바일에서 Enter가 전송이라 줄바꿈 불가 → 실제 키보드(pointer: fine)에서만 Enter 전송
- 서비스 워커가 index.html을 영원히 캐시 우선으로 줘서 배포해도 갱신 안 됨 → 페이지는 네트워크 우선
- 아이콘이 SVG뿐이라 iOS 홈 화면 아이콘 없음 → PNG 아이콘 생성 (`scripts/make-icons.mjs`)
- 키를 넣으면 계정 정보(등급·Anlas)를 자동으로 불러와 "Opus 무료" 표시가 맞게 나옴
- 시각 디자인을 읽기 중심 톤으로 다듬음 (라이트/다크 모두)
