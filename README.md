# NAI 스튜디오

NovelAI API 키 하나로 **소설 쓰기 · 캐릭터 채팅 · 이미지 생성**을 하는 모바일 웹앱(PWA)이에요.
영어로 학습된 NovelAI 모델이 영어로 쓰면, NovelAI의 GLM이 한국어로 번역해서 보여줘요.

```
[한국어 입력] → GLM: 한→영 → 글쓰기 모델(GLM / Xialong / Erato / Kayra): 영어로 생성 → GLM: 영→한 → [한국어로 표시]
```

- 서버가 없어요. 폰 브라우저가 NovelAI에 직접 요청하고, API 키와 글은 그 기기에만 저장돼요.
- 원문(영어)을 그대로 보관하기 때문에 언제든 원문 보기, 함께 보기, 다시 번역을 할 수 있어요.

## 처음 쓰는 법

1. NovelAI 웹 → 설정(⚙) → Account → **Get Persistent API Token**에서 `pst-`로 시작하는 키를 받아요.
2. 앱의 **설정** 탭에 키를 붙여 넣어요. 등급과 Anlas가 표시되면 끝이에요.
3. 키 없이 둘러보려면 **데모 모드**를 켜요. 가짜 응답으로 모든 화면을 써볼 수 있어요.

### 방법 2. GitHub Pages 주소로 열고 앱처럼 설치 (추천)

**https://kwv-max.github.io/nai-studio/**

폰에서 이 주소를 열고 브라우저 메뉴에서 **홈 화면에 추가**를 누르면 앱처럼 실행돼요(오프라인에서도 화면이 열려요). PC는 꺼져 있어도 돼요.

코드를 고친 뒤 사이트를 갱신하려면 아래 명령을 실행해요. 빌드한 결과물을 `gh-pages` 브랜치에 올리고, 1~2분 뒤 반영돼요.

```bash

```

## 기능

| 탭 | 할 수 있는 것 |
|---|---|
| 소설 | 시스템 프롬프트(메모리)·작가 노트 설정, AI 이어쓰기, "다음 장면에서 ~" 같은 지시, 직접 쓰기, 문단 수정/다시 쓰기/다시 번역/삭제, 한국어·원문·함께 보기 |
| 채팅 | 캐릭터 이름·시스템 프롬프트·첫 메시지 설정, 한국어로 대화, 다시 생성, 메시지 수정, 입력 없이 계속 말하게 하기 |
| 이미지 | 한국어 묘사 → 장면 프롬프트 + 캐릭터별 프롬프트(위치 포함)로 자동 변환 → 생성, 갤러리, 같은 시드로 다시, 저장/공유. 소설·채팅의 "이 장면 그리기"는 그 소설·대화 설정의 인물 외형을 참고해요 |
| 설정 | 모델 선택, 출력 방식, 창의성·길이, 번역 스타일, 백업 내보내기/가져오기 |

**용어집:** 소설·채팅 설정에서 `Elise → 엘리제 (반말, 차분함)`처럼 적어 두면, 번역할 때마다 이름 표기와 말투가 고정돼요. "자동 추출"을 누르면 본문에서 이름을 찾아 제안해 줘요.

**출력 방식:**
- 영어로 쓰고 한국어로 번역 (기본)
- 한국어로 바로 쓰기: GLM 계열만 가능해요. 빠르지만 문장 품질은 모델의 한국어 실력에 달려 있어요.

## 모델

| 모델 | 방식 | 메모 |
|---|---|---|
| GLM-4.6 | 대화형 (`/oa/v1/chat/completions`) | 모든 등급. 번역도 이 모델이 맡아요 |
| Xialong | 대화형 | GLM-4.6 기반 창작 특화, Opus 전용 |
| Erato | 이어쓰기 (`/ai/generate-stream`) | 영어 소설 문장력이 좋아요. 시스템 프롬프트는 메모리로, 지시는 `{ }` 지시 모드로 들어가요 |
| Kayra | 이어쓰기 | 구형 |

이미지 모델은 **V5 Full**이 기본이고 V5 Curated, V4.5, V4, V3도 고를 수 있어요. 모델을 바꾸면 가이던스·스텝·네거티브가 그 모델의 기본값으로 따라 바뀌어요(직접 바꾼 값은 유지).

- V4.5 이하: Opus 등급이면 1024×1024 이하, 28스텝 이하 1장이 무료예요("Opus 무료").
- V5: Opus도 무제한이 아니라 천천히 충전되는 한도를 써요("한도 내 무료"). 한도를 넘으면 Anlas가 들어요. V5에서는 투명 배경 옵션도 쓸 수 있어요.

### 이미지 태그 변환

GLM이 NovelAI 공식 프롬프트 규칙에 맞춰 묘사를 바꿔요.

- **장면 프롬프트:** 인원 태그(`1girl, 1boy`) → 구도 → 장소 → 시간·조명 순서로 써요.
- **캐릭터 프롬프트:** 두 명 이상이면 인물마다 따로 써서 머리색·옷 같은 특징이 섞이지 않게 해요(V4.5는 최대 6명, V5는 22명). 상호작용은 `source#hug` / `target#hug` / `mutual#holding hands` 태그로 표시하고, 위치(왼쪽·가운데·오른쪽 등)도 정해요.
- **모델별 규칙:** V3처럼 캐릭터 프롬프트가 없는 모델은 한 줄로 합쳐요. V5에서는 짧은 영어 문장과 `Text:` 글자 넣기도 허용해요.
- **결과 다듬기:** 품질 태그는 앱이 붙이므로 GLM이 쓴 건 지우고, 밑줄은 공백으로 바꾸고, 중복을 정리해요.
- **꼼꼼한 변환:** 옵션의 "태그 변환 때 GLM이 먼저 생각하기"를 켜면 느리지만 더 꼼꼼해져요.

## 알아둘 점

- **실제 키로는 아직 시험하지 않았어요.** 요청 형식은 NovelAI 공식 API 명세와 SillyTavern 구현에 맞췄고, 앱 전체 흐름은 데모 모드로 확인했어요. 처음 실제 키로 쓸 때 오류 메시지가 뜨면 그 문구를 알려 주세요.
- NovelAI는 동시에 여러 생성을 받지 않아요. 그래서 앱도 한 번에 하나씩만 생성하고, 번역은 영어 생성이 끝난 뒤에 시작해요.
- NovelAI 약관상 생성은 사람이 직접 눌러서 시작해야 해요. 앱은 자동 반복 생성이나 자동 재시도를 하지 않아요.
- 글과 이미지는 그 브라우저에만 저장돼요. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 **설정 → 백업 내보내기**를 해 두세요.

## 개발

```bash
npm test
```

```bash
npm run build
```

- `src/core/`: NovelAI 호출, 번역 파이프라인, 저장소 (프레임워크 무관, 테스트 포함)
  - `studio.ts`: 소설·채팅·이미지 작업 단위. 문서를 받아 갱신된 사본을 돌려줘요
  - `nai.ts`: API 클라이언트, `translate.ts`: 번역, `prompts.ts`: 모든 프롬프트, `mock.ts`: 데모 모드
- `src/ui/`: React 화면 (Gemini가 만들고 Claude가 검토·수정)
- `scripts/make-icons.mjs`: 앱 아이콘 생성, `scripts/clean.mjs`: 빌드 전 `dist` 정리
  - Node 24의 `fs.rmSync`가 이 폴더 경로(한글)에서 죽는 문제가 있어서 Vite 대신 이 스크립트가 `dist`를 비워요.
